# SEO-чеклист — SkyLine

Полный чек-лист SEO-оптимизации лендинга SkyLine на 2026 год.
Покрывает техническое SEO, контентное, локальное (geo-SEO), поведенческие факторы и внешние ссылки.

> Чек-лист рассчитан на 40-50 пунктов. Пройдите все по очереди — даже если что-то уже сделано, перепроверка не повредит.

---

## 1. Техническое SEO (на странице)

### Мета-теги

- [ ] `<title>` — уникальный, 50-60 символов, с главным ключом в начале: «Натяжные потолки в Иглино и Уфе — SkyLine»
- [ ] `<meta name="description">` — 140-160 символов, с гео и CTA: «Натяжные потолки в Иглинском районе и Уфе. Монтаж за 2 дня, гарантия 15 лет, цена от 490 ₽/м². Бесплатный замер.»
- [ ] `<meta name="keywords">` — 5-10 ключей (Яндекс ещё учитывает): «натяжные потолки Иглино, натяжные потолки Уфа, монтаж натяжных потолков Башкортостан, потолки под ключ»
- [ ] `<meta name="author">` — SkyLine
- [ ] `<meta name="robots">` — `index, follow, max-image-preview:large`
- [ ] `<link rel="canonical">` — `https://skyline-bashkortostan.ru/`
- [ ] `<meta name="viewport">` — `width=device-width, initial-scale=1, viewport-fit=cover`

### Open Graph и Twitter

- [ ] `og:title`, `og:description`, `og:type=website`, `og:url`, `og:image`, `og:locale=ru_RU`, `og:site_name`
- [ ] `og:image` — 1200x630, размер < 1 MB, в `<head>` указан абсолютный URL
- [ ] `twitter:card=summary_large_image`, `twitter:title`, `twitter:description`, `twitter:image`
- [ ] Twitter-аккаунт (если есть): `twitter:site=@...`

### Структура HTML

- [ ] Один `<h1>` на страницу — главный заголовок с ключом и гео
- [ ] Иерархия H2 → H3 → H4 без пропусков уровня
- [ ] Семантические теги: `<header>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`, `<nav>`
- [ ] `<article>` для отзывов и кейсов
- [ ] `<address>` в контактах
- [ ] Breadcrumb через `<nav>` с `aria-label="breadcrumbs"` + JSON-LD `BreadcrumbList`

### Изображения

- [ ] Все `<img>` имеют `alt` (описательный для контентных, пустой для декоративных)
- [ ] `loading="lazy"` для всех некритичных изображений (ниже первого экрана)
- [ ] `width` и `height` для всех изображений (анти-CLS)
- [ ] Формат WebP или AVIF (с fallback на JPG)
- [ ] `srcset` и `<picture>` для адаптивных изображений
- [ ] Размер hero-изображения < 200 KB
- [ ] Превью портфолио < 100 KB каждое

### Производительность

- [ ] Lighthouse Performance ≥ 90 (Mobile)
- [ ] LCP (Largest Contentful Paint) < 2.5 сек
- [ ] FID (First Input Delay) < 100 мс
- [ ] CLS (Cumulative Layout Shift) < 0.1
- [ ] INP (Interaction to Next Paint) < 200 мс
- [ ] Inline-критичный CSS в `<head>` (above-the-fold)
- [ ] Некритичный CSS грузится асинхронно (`media="print" onload`)
- [ ] JS с `defer` или в конце `<body>`
- [ ] Preload для шрифтов: `<link rel="preload" as="font" type="font/woff2" crossorigin>`
- [ ] `font-display: swap` для Google Fonts
- [ ] Gzip/Brotli сжатие на сервере
- [ ] HTTP/2 или HTTP/3 включён
- [ ] Длинный кэш статики (1 год + immutable)

### URL и навигация

- [ ] HTTPS включён (редирект 301 с HTTP)
- [ ] www → non-www (или наоборот) — единый канонический хост
- [ ] Без слеша на конце / со слешем — единый стиль
- [ ] Без `index.html` в URL (настройте nginx/Apache)
- [ ] 404 страница — дружелюбная, с поиском и ссылками
- [ ] 301-редиректы со старых URL (если были)
- [ ] Якорные ссылки на секции: `#calc`, `#portfolio`, `#contacts`

## 4. Контентное SEO

### Ключевые слова

- [ ] Семантическое ядро собрано (Яндекс.Вордстат, Keyword Planner)
- [ ] Главные ключи: «натяжные потолки Иглино», «натяжные потолки Уфа», «натяжные потолки Башкортостан»
- [ ] Длинные хвосты: «натяжные потолки с подсветкой Уфа», «парящие потолки Иглино», «двухуровневые потолки Башкортостан»
- [ ] Ключи в H1, H2, текстах, alt, мета-тегах — без переспама (плотность 1-3%)
- [ ] LSI-слова: «монтаж», «установка», «замер», «гарантия», «под ключ», «MSD», «Pongs», «Descor», «Clipso»

### Тексты

- [ ] Уникальность текстов ≥ 90% (text.ru, content-watch.ru)
- [ ] Объём текста на странице ≥ 1500 слов (для одностраничника — суммарно)
- [ ] Текст разбит на абзацы по 2-4 строки
- [ ] Списки (`<ul>`, `<ol>`) для перечислений
- [ ] Таблицы (`<table>`) для прайс-листов
- [ ] Цитаты (`<blockquote>`) для отзывов
- [ ] Внутренние ссылки на секции (якоря)

### Прайс-лист

- [ ] Цены указаны (от 490 ₽/м²)
- [ ] Что входит в цену — отдельный блок
- [ ] Таблица с ценами по типам полотна
- [ ] JSON-LD `Offer` для каждой услуги
- [ ] Калькулятор стоимости (уже есть в проекте)

## 6. Поведенческие факторы

- [ ] Время на сайте ≥ 60 сек
- [ ] Глубина просмотра ≥ 2 страниц (или скролл на 80%+ для лендинга)
- [ ] Отказы < 40%
- [ ] CTA кнопки — крупные, контрастные, с понятным текстом
- [ ] Форма заявки — короткая (имя + телефон), не более 5 полей
- [ ] Мгновенный отклик на действия (ripple, hover, focus)
- [ ] Scroll-to-top — для удобства навигации
- [ ] Скорость загрузки формы < 2 сек
- [ ] Спасибо-страница после отправки заявки (или модалка)

## 13. Чёрный список (что НЕ делать)

- [ ] НЕ закупать ссылки на биржах (Яндекс и Google наказывают)
- [ ] НЕ использовать скрытый текст (display:none с ключевиками)
- [ ] НЕ использовать дорвеи
- [ ] НЕ копировать контент у конкурентов (пессимизация за неуникальность)
- [ ] НЕ переспамить ключами (плотность > 5% — фильтр)
- [ ] НЕ использовать automated link building
- [ ] НЕ накручивать поведенческие факторы ботами (пессимизация)
- [ ] НЕ покупать фейковые отзывы (блокировка карточки)
- [ ] НЕ игнорировать негативные отзывы (отвечайте конструктивно)
- [ ] НЕ забывать обновлять цены и контактные данные
